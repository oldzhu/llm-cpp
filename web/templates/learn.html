How a GPT Works — From Text to Next Token

Follow the journey of text through a Transformer, step by step. Click any code link to see the C++ implementation.

1

Tokenization

Text is split into tokens — the smallest units the model processes.

Byte tokenizer: Each byte (0–255) is a token. Simple, fast, vocabulary size = 256.

BPE tokenizer: Common character pairs are merged into subword tokens (GPT-2 uses 50,257 tokens). More efficient but more complex.

"hello" → [104, 101, 108, 108, 111]

2

Embeddings

Token IDs are meaningless numbers. Embeddings convert them into meaningful vectors in a high-dimensional space.

Token embedding: Each token ID looks up a row in a table wte[V, C] → gets a C-dimensional vector.

Position embedding: Since attention has no built-in order sense, we add wpe[pos] to encode position.

X[b,t] = Wte[tokens[b,t]] + Wpe[t]
wte: [V,C]   wpe: [T,C]   X: [B,T,C]

3

Causal Self-Attention

Each token looks at all previous tokens (causal mask — can't see the future) and decides which ones are relevant.

Step 1 — QKV Projection: Input X is projected into three matrices: Query (what am I looking for?), Key (what do I offer?), Value (what information do I carry?).

Step 2 — Scores: For each position i, compute dot product with all keys j ≤ i: S[i,j] = Q[i]·K[j] / √C

Step 3 — Softmax + Weighted Sum: Convert scores to probabilities, then compute weighted sum of values: Y[i] = Σ_j softmax(S[i,j]) · V[j]

Q,K,V = X·Wqkv + bqkv
S[i,j] = Q[i]·K[j]/√C + mask(j>i→-∞)
P = softmax(S)
Y[i] = Σ_j P[i,j]·V[j]
Wqkv: [C,3C]   Q/K/V: [B,T,C]   Scores: [B,T,T]

4

Multi-Head Attention (Variant)

Instead of one attention, use multiple heads. Each head looks at different aspects of the tokens.

Split: C = n_heads × head_dim. Q,K,V reshaped to [B,T,n_heads,head_dim].

Per head: Attention computed independently.

Concat: Heads concatenated back to [B,T,C] and projected.

C = H×D   Q_h,K_h,V_h: [B,T,D]
S_h[i,j] = Q_h[i]·K_h[j]/√D + mask
Y = concat(Y_0,...,Y_{H-1})·Wproj

5

Feed-Forward Network (MLP)

After attention, each token goes through a small neural network independently. This adds non-linearity and capacity.

Standard (GELU): Two linear layers with GELU activation: FF = GELU(X·Wfc + bfc)·Wout + bout

SwiGLU (Variant): Gated variant: gate = SiLU(X·Wg), up = X·Wu, FF = (gate⊙up)·Wd

MoE (Variant): Multiple expert FFNs with a router that selects which experts to use per token.

GELU: FF = GELU(X·Wfc)·Wout
SwiGLU: FF = (SiLU(X·Wgate)⊙(X·Wup))·Wdown

6

LayerNorm & RMSNorm

Normalization keeps values in a healthy range so training doesn't diverge or stall.

LayerNorm: Subtract mean, divide by standard deviation, then apply learnable scale γ and shift β.

RMSNorm: Simpler — just divide by RMS. No mean subtraction. Used in LLaMA.

LayerNorm: y = (x-μ)/σ·γ + β
RMSNorm: y = x/rms·γ
γ: [C]   β: [C] (LN only)
📄 layernorm_affine() + rmsnorm_affine()
7

Training Loop

How the model learns from data — the engine that turns random weights into a language model.

Forward pass: Tokens → embeddings → layers → LM head → logits [B,T,V]

Loss: Cross-entropy between predicted probabilities and actual next token. L = -log(p_correct)

Backward: Compute ∂L/∂w for every parameter using chain rule (autograd).

Optimizer step: AdamW updates weights: w ← w - lr · m/(√v + ε) - lr·λ·w (with momentum m, velocity v, and weight decay λ).

Forward: X = Embed(tokens) → layers → logits
Loss: CE = -1/N Σ log(p_target)
Backward: ∂L/∂w (autograd graph)
Update: w -= lr * AdamW(gradient)
