# Chat Session 2026-05-12 — Affine LayerNorm Implementation

> [简体中文](#聊天会话-2026-05-12--affine-layernorm-实现)

## Summary

Added affine LayerNorm (gamma/beta parameters) to the baseline model, following the project lifecycle guidelines. This is a model fidelity upgrade — the third recommended next step after KV-cache.

## What Was Done

### 1. New operation: `layernorm_affine`
- `src/ops.h` / `src/ops.cpp`: Added `nn::layernorm_affine(x, gamma, beta, eps)`
- Forward: `y_i = ((x_i - mean) / sqrt(var + eps)) * gamma_i + beta_i`
- Backward: Full autograd for both x and gamma/beta (verified by finite-diff gradcheck)
- gamma: `[D]`, beta: `[D]`, initialized to gamma=1.0, beta=0.0 (identity behavior)

### 2. Model parameter additions
- `model.h`: Added `ln_attn_gamma/beta`, `ln_mlp_gamma/beta` to each `Block`, plus `ln_final_gamma_/beta_`
- `model.cpp`: 
  - Constructor initializes gamma → 1.0, beta → 0.0
  - `forward_logits` uses `layernorm_affine` for all 2*n_layers+1 LayerNorm positions
  - `zero_grad`, `parameters()`, `parameters_const()` include new tensors

### 3. KV-cache variant update
- `src/variants/kvcache/kvcache_attention.cpp`: Updated param indices from `base=2+li*8` to `base=2+li*12` and uses `layernorm_affine` instead of `layernorm_lastdim`. Ensures KV-cache outputs match baseline identically.

### 4. Checkpoint versioning
- Save: bumped `version` from 1 → 2 (JSON + binary)
- Load v2: normal, all 18 params per layer
- Load v1: maps old param indices to new positions, initializes LN params to identity
- Optimizer state: v1 compat (only loads old params' state, zeros for new LN params)

### 5. Tests
- `test_gradcheck_layernorm_affine_via_cross_entropy()`: Finite-difference gradcheck for dL/dx, dL/dgamma, dL/dbeta
- All existing tests continue to pass

## Verification
- `ctest -C Debug`: 10/10 tests pass
- `cmake --build`: 0 warnings
- Baseline vs KV-cache: identical output (bit-for-bit)
- V1 checkpoint backward compat: loads and generates correctly
