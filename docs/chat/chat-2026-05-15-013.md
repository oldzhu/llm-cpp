# Chat Session 2026-05-15 — BPE Token-Level Full Pipeline Test

> [简体中文](#聊天会话-2026-05-15--bpe-token级完整流水线测试)

## Summary

Ran a complete BPE token-level training + inference pipeline. Fixed the GPT-2 byte-to-unicode mapping in BpeTokenizer for correct encode/decode. Model trained on tokenized text and generated recognizable English text.

## What Was Done

### 1. BPE Tokenizer Fix
- Implemented `bytes_to_unicode()` mapping — GPT-2's standard byte representation
- Raw bytes 0-255 mapped to unicode characters (printable ASCII stays, others → higher codepoints)
- Fixed `encode()` to use byte mapping for initial split
- Fixed `decode()` to reverse-map unicode codepoints back to bytes
- Result: correct tokenization matching GPT-2 behavior

### 2. BPE Training
```
Model:    d_model=32, layers=1, seq=32, batch=4
Vocab:    50,257 GPT-2 tokens
Data:     20,643 chars → 5,313 BPE tokens (3.9× compression)
Steps:    200
Time:     139s (Release build)
Loss:     11.3 → 5.5 (random = ~10.8, clearly learning)
```

### 3. BPE Generation
```
Prompt:  "It was a"
Output:  "the a-- on. at. I a.:--, and up that had his him
         -- theI he I . was , , ., you-- the the the to.
         :. to a of't been one on"

Observations:
- Real English words: "the", "and", "had", "him", "was", "you", "been", "one"
- Source-style punctuation: "--" (dialogue marks from The Verdict)
- Paragraph formatting with newlines
- Learned character-level patterns consistent with training data
```

### 4. Comparison: Byte vs BPE

| | Byte (vocab=256) | BPE (vocab=50,257) |
|---|---|---|
| Speed | 33s / 300 steps | 139s / 200 steps |
| Compression | 1:1 | 3.9:1 (chars→tokens) |
| Quality (200 steps) | Character fragments | Real words |
| Memory | 16K embed | 1.6M embed |
| Code | Simple, fast | Full GPT-2 pipeline |

### 5. Key findings
1. BPE token-level training WORKS end-to-end
2. Quality is better per step (real words emerge faster)
3. Speed is ~5× slower due to 200× larger embedding/LM head
4. Bytes_to_unicode mapping is essential for correct BPE encode/decode
