# Chat Session 2026-05-29 — Safetensors Import (GPT-2 + LLaMA)

## Summary
Created import pipeline to convert HuggingFace safetensors models to our native checkpoint format. GPT-2 mapping with identity/transpose ops, LLaMA mapping with concat+pad for GQA. Network speed blocked 330MB model download — everything else complete.

## What Was Done

### 1. Mapping Files (scripts/mappings/)
- `gpt2.json` — 18 params: identity for biases/LN, transpose for w_qkv/w_fc/w_out/w_lm, zeros for SwiGLU/MoE
- `llama.json` — Concatenates separate Q/K/V into w_qkv, pads K/V for GQA, zeros for biases/wpe, maps SwiGLU params

### 2. Main Converter (scripts/import_safetensors.py)
- Reads config.json → extracts V, T, C, n_layers
- Reads model.safetensors (single or sharded)
- Applies per-param operations: identity, transpose, zeros, transpose_or_wte, llama_qkv
- For GQA: pads K/V projections from n_kv*hd → C width with zeros
- Writes our native checkpoint (.json + .bin) in exact binary format
- Optional `--copy-tokenizer` flag copies vocab/merges files
- Sharded model support (.index.json weight map)

## Usage Commands

```powershell
# 1. Download model from HuggingFace
python -c "from huggingface_hub import snapshot_download; snapshot_download('distilgpt2', local_dir='data/distilgpt2')"
# OR manually download from https://huggingface.co/distilgpt2 → download all files to data/distilgpt2/

# 2. Install deps
pip install -r scripts/requirements.txt

# 3. Import
python scripts/import_safetensors.py data/distilgpt2/ data/ckpt_distilgpt2 --mapping gpt2

# 4. Verify
.\build\Release\train_gpt.exe --load data/ckpt_distilgpt2 --steps 0 --prompt "Hello" --gen 30

# 5. Continue training (SFT)
.\build\Release\train_gpt.exe --load data/ckpt_distilgpt2 --data data/alice.txt --steps 500 --save data/ckpt_distilgpt2_sft
```
