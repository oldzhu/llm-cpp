## Summary

Implemented the Rotary Positional Embedding (RoPE) variant, following the project lifecycle guidelines. RoPE encodes position information by rotating Q and K vectors, producing relative position awareness without learned absolute position embeddings.

## Design Decisions
1. Rotation applied to Q and K only (V is not rotated — standard RoPE)
2. In-place rotation (modifies tensor data directly)
3. base=10000 (standard RoFormer convention)
4. Requires even C (pairs of dimensions rotated together)
