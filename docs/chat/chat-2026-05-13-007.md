# Chat Session 2026-05-13 — Vulkan Compute Backend

> [简体中文](#聊天会话-2026-05-13--vulkan-计算后端)

## Summary

Designed and implemented a Vulkan compute backend as an optional GPU backend. Uses the existing `KernelBackend` seam. POC mode: host↔device copies per call, forward matmul only.

## What Was Done

### 1. GLSL Compute Shader
- `shaders/matmul_fwd.comp` — Standard GLSL matmul: C[M,N] = A[M,K] @ B[K,N]
- 16×16 workgroups, push constants for M,K,N

### 2. C++ Vulkan Backend
- `src/backend/vulkan/vulkan_backend.h` — Header
- `src/backend/vulkan/vulkan_backend.cpp` — Full Vulkan compute pipeline:
  - Dynamic loading of vulkan-1.dll (no static link dependency at runtime)
  - Instance → physical device → logical device → compute queue
  - SPIR-V shader loading from file
  - Per-call: buffer create/upload/dispatch/readback/destroy
  - `is_ready()` check — falls back to CPU if Vulkan unavailable
  - Backward pass delegates to CpuBackend

### 3. Build System
- CMake: `option(BUILD_VULKAN)` (default OFF)
- `find_package(Vulkan REQUIRED)` when enabled
- Automatic shader compilation via `glslc` at build time
- `target_compile_definitions(llm_core PUBLIC BUILD_VULKAN)` for conditional compilation
- Test conditionally compiled with `#ifdef BUILD_VULKAN`

### 4. Test
- `test_vulkan_matches_cpu_matmul()` — Compares Vulkan fwd matmul output against CPU reference (3 size configs)
- Reports `[SKIP]` when BUILD_VULKAN=OFF
- Reports `[SKIP]` when Vulkan GPU not available

### 5. Doc
- `docs/notes/2026-05-13_vulkan_backend_setup.md` + `.zh-CN.md` — Setup instructions

## Verification
- `ctest -C Debug` (BUILD_VULKAN=OFF): 16/16 tests pass
- Vulkan test correctly skips when not built
- Code compiles cleanly (0 warnings)
