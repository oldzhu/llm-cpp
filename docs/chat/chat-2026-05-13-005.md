## Summary

Implemented the Grouped-Query Attention (GQA) variant. GQA reduces KV-cache memory by having fewer K/V heads than Q heads, with multiple Q heads sharing the same K/V head.

### 2. Code
- `src/variants/gqa/gqa_attention.h` — API with 4D tensor inputs
- `src/variants/gqa/gqa_attention.cpp` — Full implementation with autograd:
  - `self_attention_gqa(q_4d, k_4d, v_4d, n_heads, n_kv_heads)` → [B,T,Hq*D]
  - Head mapping: kv_idx = q_head * n_kv_heads / n_heads
  - Requires n_heads % n_kv_heads == 0

## Design Decisions
1. Takes pre-split 4D tensors (Q, K, V already split into heads) — keeps API focused on GQA logic
2. Full autograd for Q and K (backward correctly handles shared K/V heads)
3. kv_idx = q_head * n_kv_heads / n_heads (standard group mapping)
