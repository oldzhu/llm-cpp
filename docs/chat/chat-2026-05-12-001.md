## Project State Summary

### Architecture
- CPU FP32 GPT-style decoder-only Transformer in C++
- Custom autograd engine with Node-based backward graph
- Backend seam: `KernelBackend` interface routes `matmul2d`/`bmm` through swappable backends (CPU, planned CUDA/HIP)
- Pluggable tokenizers: `ByteTokenizer` (default, V=256) + `BpeTokenizer` (import-style)
- MHA variant implemented side-by-side in `src/variants/mha/`

### Source Layout
```
src/
├── tensor.cpp/h       — Tensor + autograd Node + grad mode
├── ops.cpp/h          — All nn ops (matmul, softmax, layernorm, attention, etc.)
├── model.cpp/h        — TinyGPT: embeddings, blocks, forward_logits, loss
├── optim.cpp/h        — AdamW optimizer
├── checkpoint.cpp/h   — Save/load (JSON config + binary weights)
├── data.cpp/h         — ByteDataset for byte-level training
├── util.cpp/h         — RNG, file I/O
├── main.cpp           — CLI: training, generation, sanity checks
├── backend/
│   ├── backend.h      — KernelBackend interface (matmul2d_fwd/bwd)
│   ├── cpu_backend.*  — CPU GEMM loops
│   └── registry.*     — Global backend selection
├── tokenizer/
│   ├── tokenizer.h    — Abstract Tokenizer interface
│   ├── byte_tokenizer.*
│   └── bpe_tokenizer.*
└── variants/mha/
    └── mha_attention.* — MHA (single-head verified equivalent)
```
