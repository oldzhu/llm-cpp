# Chat Session 2026-05-13 — RMSNorm Implementation

> [简体中文](#聊天会话-2026-05-13--rmsnorm-实现)

## Summary

Implemented RMSNorm (Root Mean Square Normalization), the simpler norm variant used in LLaMA models. Added as a configurable option alongside LayerNorm. `--norm rmsnorm` CLI flag.

## What Was Done

### 1. Operations
- `nn::rmsnorm_lastdim(x, eps)` — Non-affine version
- `nn::rmsnorm_affine(x, gamma, eps)` — Affine version (gamma only, no beta)
- Forward: y_i = x_i / sqrt(mean(x^2) + eps) * gamma_i
- Backward: dL/dx_i = (dL/dz_i - z_i * mean(dL/dz * z)) / rms (simpler than LayerNorm — no mean subtraction term)
- Full autograd for x and gamma

### 2. Model integration
- `model::Config::norm_type`: 0 = LayerNorm (default), 1 = RMSNorm
- `model.cpp`: Uses rmsnorm_affine when norm_type==1 (reuses gamma, ignores beta)
- CLI: `--norm layernorm|rmsnorm`
- KV-cache variant updated to respect norm_type

### 3. Tests
- `test_gradcheck_rmsnorm_affine_via_cross_entropy()`: Finite-diff gradcheck for dL/dx and dL/dgamma
- All existing tests pass

## Verification
- `ctest -C Debug`: 17/17 tests pass, 0 failures
- `cmake --build`: 0 warnings
- Baseline vs KV-cache with RMSNorm: identical output
- Training with RMSNorm: loss decreases correctly (6.06 → 3.79)

## Design decisions
1. Reuses existing gamma params (beta is ignored for RMSNorm — still stored but unused)
2. Same parameter count regardless of norm_type
3. Compile-time selection via config, not separate variant
