# Chat Session 2026-05-15 — BPE Token-Level Training

> [简体中文](#聊天会话-2026-05-15--bpe-token级训练)

## Summary

Enabled GPT-2 BPE token-level training. Downloaded real GPT-2 vocabulary (50,257 tokens), added TokenDataset, JSON vocab parser, and --tokenize-output mode. Complete pipeline: text → tokenize → train → generate with BPE tokens.

## What Was Done

### 1. GPT-2 Tokenizer Files
- `data/bpe_vocab.json` (1MB, 50,257 tokens) — downloaded from Hugging Face
- `data/bpe_merges.txt` (456KB) — BPE merge rules
- Updated BpeTokenizer to parse JSON vocab format (auto-detects plain vs JSON)

### 2. TokenDataset
- `data.h/.cpp`: New `TokenDataset` class — loads int32 token IDs, samples batches
- Mirrors ByteDataset API for seamless swap

### 3. New CLI flags
- `--tokenize-output FILE`: Read text data, tokenize with BPE, write binary int32 token IDs
- `--token-data FILE`: Load pre-tokenized IDs for training

### 4. End-to-end test
```
Tokenize:  20K chars → 5,767 tokens (3.6× compression, 0.28 ratio)
Training:  BPE with vocab=50257, works (slow due to large vocab)
Generation: Uses BpeTokenizer::decode() to detokenize output
```

## Why byte-level for learning

| | Byte (vocab=256) | BPE (vocab=50,257) |
|---|---|---|
| Speed | Fast (33s/300 steps) | Very slow (~200× larger matmul) |
| Memory | Tiny wte/lm matrices | 50K×d_model each |
| Quality | OK with more steps | Better per step |
| **Teaching** | Fast iteration | Real GPT pipeline |

**Recommendation**: Use byte-level for learning (fast iteration). BPE pipeline works for final product.

## Full pipeline commands
```powershell
# Byte-level (recommended for learning)
.\build\Release\train_gpt.exe --data .\data\alice.txt --steps 2000 --batch 8 --seq 80 --dmodel 100 --layers 2 --lr 0.0005 --save .\data\ckpt --log-loss .\data\loss.csv
.\build\Release\train_gpt.exe --load .\data\ckpt --steps 0 --prompt "Alice" --gen 200 --temp 0.8 --topk 40

# BPE token-level
.\build\Debug\train_gpt.exe --tokenizer bpe --bpe-vocab .\data\bpe_vocab.json --bpe-merges .\data\bpe_merges.txt --data .\data\alice.txt --tokenize-output .\data\alice_tokens.bin
.\build\Release\train_gpt.exe --tokenizer bpe --bpe-vocab .\data\bpe_vocab.json --bpe-merges .\data\bpe_merges.txt --token-data .\data\alice_tokens.bin --steps 500 --batch 4 --seq 64 --dmodel 32 --layers 1 --lr 0.0005
```
