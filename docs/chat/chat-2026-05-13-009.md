# Chat Session 2026-05-13 — SiLU + SwiGLU Implementation

> [简体中文](#聊天会话-2026-05-13--silu--swiglu-实现)

## Summary

Added SiLU activation and SwiGLU MLP (gated feed-forward network), the modern FFN used in LLaMA. `--mlp swiglu` CLI flag. Checkpoint version 3.

## What Was Done

### 1. SiLU Activation
- `nn::silu(x)`: SiLU / Swish — silu(x) = x * sigmoid(x)
- Full autograd: d/dx = sigmoid(x) + y * (1 - sigmoid(x))
- Gradcheck verified

### 2. SwiGLU MLP
- Config::mlp_type: 0=GELU (default), 1=SwiGLU
- SwiGLU: gate = SiLU(x @ w_gate + b_gate); up = x @ w_up + b_up; out = (gate ⊙ up) @ w_down + b_down
- 6 new params per block: swiglu_gate[C,interm], swiglu_gate_b[interm], swiglu_up[C,interm], swiglu_up_b[interm], swiglu_down[interm,C], swiglu_down_b[C]
- interm = cfg.swiglu_interm > 0 ? cfg.swiglu_interm : 3*d_model
- Appended at end of params array (no index change for existing params)

### 3. Checkpoint v3
- Save with version=3 (includes SwiGLU params)
- Load v1/v2: SwiGLU params initialized to zeros (backward compat)

### 4. KV-cache updated
- model_prefill/model_step: SwiGLU path support

### 5. Tests
- `test_gradcheck_silu_via_cross_entropy()`: Finite-diff gradcheck for SiLU

## Verification
- `ctest -C Debug`: 18/18 tests pass, 0 failures, 0 warnings
- Training with SwiGLU: loss 5.96 → 3.82 (50 steps)
- Baseline vs KV-cache with SwiGLU: identical output
- V2 checkpoint loaded with --mlp gelu: backward compat OK
