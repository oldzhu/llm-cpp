# Chat Session 2026-05-27 — Web UI Phase 3 (Code Explorer + AI Chat)

## Summary
Added Code Explorer and AI Chat tabs to the web UI. Browsable file tree, syntax-highlighted code viewer with click-to-select, AI-powered code explanation. Jinja2 template bug discovered and fixed (static HTML rendering).

## What Was Done

### 1. Code Explorer (`web/code.py`)
- `/api/code/tree` — browsable directory tree of src/, docs/, tests/
- `/api/code/file?path=src/ops.cpp` — serves file content with line numbers
- Path traversal protection
- Project context builder for AI chat

### 2. AI Chat (`web/ai_chat.py`)
- `/api/chat/send` — general chat with project-aware system prompt
- `/api/chat/explain` — explain selected code lines
- Supports OpenAI-compatible API (Anthropic, DeepSeek, etc.)
- Pre-loaded project context summarizes all source files
- Clear error when API key not configured

### 3. Frontend
- `templates/code.html` — Three-column layout: file tree | code viewer | AI panel
- `templates/chat.html` — Standalone chat with message history
- `static/code.js` — CodeUI class: file tree rendering, click-to-select, AI explain
- `static/chat.js` — ChatUI class: send/receive, markdown rendering
- Line highlighting, shift-click range selection

### 4. Jinja2 Cache Bug
- Jinja2 3.1.6 `LRUCache` fails with `TypeError: cannot use tuple as dict key` on template includes
- `cache_size=0` + `cache={}` doesn't fix (cache_size property doesn't reset cache)
- **Fix**: Replaced Jinja2Templates with `str.replace` static rendering — reads base.html, injects sub-templates via string substitution

### 5. API Key Setup
```powershell
copy web\.env.example web\.env
# Edit web\.env: set ANTHROPIC_API_KEY=sk-...
```
