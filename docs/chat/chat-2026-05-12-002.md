## Design Decisions

1. **No autograd in step path** — generation-only, so no backward graph built
2. **No causal mask in step** — query is at end of sequence, can attend to all
3. **Per-layer caches** — one KVCache per attention block for multi-layer models
4. **Model weights accessed via `parameters_const()`** — avoids coupling to internal member names
5. **Prefill uses same attention math as baseline** — guarantees identical output

## 设计决策

1. **step 路径无 autograd** — 仅用于生成，不构建反向图
2. **step 中无因果掩码** — 查询位于序列末尾，可关注所有位置
3. **逐层缓存** — 每层注意模块一个 KVCache
4. **通过 `parameters_const()` 访问模型权重** — 避免与内部成员名称耦合
5. **prefill 使用与基线相同的注意力数学** — 保证输出一致
