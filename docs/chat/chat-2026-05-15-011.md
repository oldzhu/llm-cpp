# Chat Session 2026-05-15 — Real Training + Inspection Pipeline

> [简体中文](#聊天会话-2026-05-15--真实训练--检查流水线)

## Summary

Set up a complete train→inspect→debug workflow on real data. Downloaded Alice in Wonderland (148KB), added `--debug-layer` and `--log-loss` features, ran 300-step training session with full inspection.

## What Was Done

### 1. Real Dataset
- Downloaded "Alice's Adventures in Wonderland" from Project Gutenberg (148KB, ~150K chars)
- Stripped header/footer, kept story text
- `data/alice.txt`

### 2. New Features
- `--debug-layer`: During generation, prints weight tensor stats (mean, rms, min, max) for wte, wpe, and each layer's w_qkv
- `--log-loss FILE`: Writes `step,loss,time` CSV for plotting/analysis

### 3. Training Session
- Model: d_model=80, layers=1, seq=80, batch=8
- 300 steps in ~30s (Release build)
- Loss: 5.93 → 2.46 (4.5 bits/byte → ~2.5 bits/byte)
- Checkpoint saved to `data/ckpt_alice.*`
- Loss CSV: `data/loss.csv`

### 4. Inspection Results
- **Next-byte sanity**: 3/5 correct (60%), expected given 300 steps on large corpus
- **Layer debug**: Weight stats visible per layer
- **Context preview**: Shows 80 chars of context with expected vs predicted byte
- **Token distribution**: Top-5 probabilities printed for each prediction

## Usage Commands

```powershell
# Train with loss logging
.\build\Release\train_gpt.exe --data .\data\alice.txt --steps 300 --batch 8 --seq 80 --dmodel 80 --layers 1 --lr 0.0005 --save .\data\ckpt_alice --log-loss .\data\loss.csv

# Generate with layer debug
.\build\Release\train_gpt.exe --load .\data\ckpt_alice --steps 0 --prompt "The Queen" --gen 100 --temp 0.8 --topk 40 --debug-layer --print-next-top 5

# Sanity: predict next bytes from dataset
.\build\Release\train_gpt.exe --load .\data\ckpt_alice --data .\data\alice.txt --steps 0 --sanity-next-from-data 10

# Exact offset check
.\build\Release\train_gpt.exe --load .\data\ckpt_alice --data .\data\alice.txt --steps 0 --sanity-offset 1000 --sanity-ctx 60 --sanity-preview 80 --sanity-top 5
```

## Training Tips
- Use `--config Release` for 3-5× speedup
- Increase `--dmodel 128 --layers 2 --steps 5000+` for better results
- `--log-loss .csv` + Excel/gnuplot to visualize learning curve
- `--debug-layer` shows weight magnitudes — watch for explosion/collapse
