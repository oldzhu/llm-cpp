# KV-cache 手算示例

目标：验证形状逻辑和"缓存完整性"——KV-cache 的 step 输出必须与完整重新计算相同。

## 配置

单批次，三个 token：
- `B=1`, `T=3`

模型宽度 `C=2`。使用微小的、手工选取的值（为简洁起见省略缩放因子）。

### 权重（保持极小）

本示例忽略 QKV 投影权重，直接使用投影后的 Q、K、V 值，聚焦于缓存机制本身。

给定（QKV 投影后）：

Token 0: `q0=[1,1]`, `k0=[1,0]`, `v0=[2,0]`
Token 1: `q1=[0,1]`, `k1=[0,1]`, `v1=[0,3]`
Token 2: `q2=[1,2]`, `k2=[2,0]`, `v2=[1,1]`

## 预填充（完整 3-token 序列）

### Scores（因果，scale=1）

Token 0 (i=0):
- j=0: `q0·k0 = 1*1 + 1*0 = 1`
- j=1: 被掩码（未来）
- j=2: 被掩码（未来）
- 行: `[1, -inf, -inf]`

Token 1 (i=1):
- j=0: `q1·k0 = 0*1 + 1*0 = 0`
- j=1: `q1·k1 = 0*0 + 1*1 = 1`
- j=2: 被掩码（未来）
- 行: `[0, 1, -inf]`

Token 2 (i=2):
- j=0: `q2·k0 = 1*1 + 2*0 = 1`
- j=1: `q2·k1 = 1*0 + 2*1 = 2`
- j=2: `q2·k2 = 1*2 + 2*0 = 2`
- 行: `[1, 2, 2]`

### Softmax 后（近似值）

Token 0: `[1.0, 0.0, 0.0]`
Token 1: `[0.269, 0.731, 0.0]`
Token 2: `[0.211, 0.576, 0.212]`

### 输出 Y（加权 V）

Y[0] = 1.0 * v0 = `[2, 0]`
Y[1] = 0.269 * v0 + 0.731 * v1 = `[0.538, 2.193]`
Y[2] = 0.211 * v0 + 0.576 * v1 + 0.212 * v2 = `[0.634, 1.940]`

### 预填充后的缓存状态

```
k_cache = [k0, k1, k2]  = [[1,0], [0,1], [2,0]]
v_cache = [v0, v1, v2]  = [[2,0], [0,3], [1,1]]
cur_len = 3
```

## 逐步（生成 token 3）

新 token QKV 投影后：`q3=[0,2]`, `k3=[1,1]`, `v3=[3,0]`

### 追加到缓存

```
k_cache = [k0, k1, k2, k3]  = [[1,0], [0,1], [2,0], [1,1]]
v_cache = [v0, v1, v2, v3]  = [[2,0], [0,3], [1,1], [3,0]]
cur_len = 4
```

### Scores（最后一个位置无需因果掩码）

q3 · k0 = 0*1 + 2*0 = 0
q3 · k1 = 0*0 + 2*1 = 2
q3 · k2 = 0*2 + 2*0 = 0
q3 · k3 = 0*1 + 2*1 = 2

行: `[0, 2, 0, 2]`

### Softmax 后

`[0.061, 0.450, 0.061, 0.450]`（近似值）

### 输出 Y[3]

Y[3] = 0.061*v0 + 0.450*v1 + 0.061*v2 + 0.450*v3
     = 0.061*[2,0] + 0.450*[0,3] + 0.061*[1,1] + 0.450*[3,0]
     = [0.122+0+0.061+1.350, 0+1.350+0.061+0]
     = `[1.533, 1.411]`（近似值）

## 验证：完整重新计算得出相同的 Y[3]

用全部 4 个 token 重新计算注意力，token 3 的得分：
- i=3: 点积与上述相同 → 相同 softmax → 相同 Y[3]。

因此缓存产生与完整重新计算 **完全相同** 的输出。

## 代码映射

预填充逻辑与 `nn::self_attention_1h` 类似，但额外将 K 和 V 写入缓存张量。

逐步逻辑在 `self_attention_step` 中：
- `src/variants/kvcache/kvcache_attention.cpp`

step 中无需因果掩码，因为 query 始终在末尾。
